# BUG-02: Поле ввода пароля отображает символы в открытом виде (нет маскирования)

* **Приоритет (Priority):** High
* **Серьезность (Severity):** Critical
* **Окружение (Environment):** Windows 11, Google Chrome v120.0

### Шаги воспроизведения:
1. Открыть форму входа.
2. Ввести любой пароль в поле «Пароль» (например, `SecretPass123`).

* **Фактический результат (Actual Result):** Вводимый пароль отображается открытым текстом (`SecretPass123`).
* **Ожидаемый результат (Expected Result):** Символы пароля должны автоматически маскироваться точками или звездочками (`••••••••••••`).
