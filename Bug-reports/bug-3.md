# BUG-03: Возможность отправки XSS-скрипта через поле «Логин/Email»

* **Приоритет:** High
* **Серьезность:** Critical
* **Окружение:** Windows 11, Google Chrome v120.0

### Шаги воспроизведения:
1. Открыть форму авторизации.
2. В поле «Логин/Email» вставить значение: `<script>alert('XSS')</script>`.
3. Ввести любой пароль и нажать кнопку «Войти».

* **Фактический результат:** Браузер выполняет код инъекции и выводит всплывающее окно `alert`.
* **Ожидаемый результат:** Строка должна экранироваться на стороне сервера/клиента, выводится ошибка формата Email.
